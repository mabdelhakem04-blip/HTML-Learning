# مشروع تعلم أساسيات HTML

هذا هو مشروعي الأول في رحلة تعلم تطوير المواقع (Front-end Development). 

## عن المشروع
المشروع عبارة عن صفحة ويب بسيطة تم إنشاؤها باستخدام لغة *HTML* فقط، ويهدف إلى تطبيق أساسيات تنسيق النصوص والعناوين.

## المهارات المستخدمة في هذا الكود:
* استخدام العناوين بمستويات مختلفة (h1 إلى h4).
* تنسيق النصوص باستخدام (mark, del, u, i).
* استخدام الرموز العلوية والسفلية (sup, sub).
* إضافة التعليقات البرمجية (Comments).

## كيف تشغل المشروع؟
1. قم بتحميل الملف index.html.
2. افتح الملف باستخدام أي متصفح ويب (Chrome أو Edge)
